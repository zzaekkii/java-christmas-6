# java-christmas

### 📌 요구사항 요약
12월 식당 메뉴 주문 예약을 받고,
해당 날짜에 적용되는 이벤트의 최종 혜택을 정리해서 알려줘야 한다.

#### 특이 사항
1. `금요일`, `토요일`이 주말
2. ★이 붙은 날은 `일요일`(3, 10, 17, 24, 31)과 크리스마스(25)
3. 크리스마스 D-day 할인은 1,000원부터 시작해 25일까지 100원씩 증가 (25일까지만 적용)
4. 총 주문금액이 10,000원 이상인 주문에 한해 이벤트 적용 가능
5. 음료만 주문 불가능
6. 주문 당 메뉴 최대 20개까지만 가능
<br/>

### 📝 구현할 기능 목록
#### 1. 사용자 주문 입력
- 조건
- [x] `Console`의 `readLine()`을 활용
- [x] 제공된 `InputView` 클래스 활용
- [x] 날짜 입력 요청 출력
- [x] 날짜를 입력 받기
- [x] 주문 메뉴와 개수 입력 요청 출력
- [x] 주문 메뉴와 개수를 입력 받기 
- [x] 메뉴 20개 까지만 가능
- 예외
- [x] 날짜가 1 이상 31 이하의 숫자가 아닌 경우, "[ERROR] 유효하지 않은 날짜입니다. 다시 입력해 주세요."
- [x] 없는 메뉴일 경우, "[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요."
- [x] 메뉴 개수가 양수가 아닐 경우, "[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요."
- [x] 메뉴 입력 형식이 잘못 된 경우, "[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요."
- [x] 중복 메뉴를 입력한 경우, "[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요."
#### 2. 주문 메뉴(음식) 객체 Menu 생성
- 조건
- [x] 이름, 가격, 타입(애피타이저, 메인, 디저트, 음료) 상태를 가짐
- [x] 타입은 VO로 Enum을 이용해 구현
- [x] 식당의 기본 메뉴 모두 등록 (검색 용이하도록 `HashMap`으로 저장)
#### 3. 주문 객체 Order 생성
- 조건
- [x] 날짜, 담은 메뉴 목록(맵)을 상태로 가짐
- [x] 예약 날짜가 특별한 날인지 평일/주말인지 판별하는 메서드
#### 4. 할인 이벤트 확인
- 조건
- [x] `Order`를 대상으로 각 이벤트가 적용 가능한지 판별 후 결과 반환
- [x] 크리스마스 D-Day 할인이 적용된다면, 이벤트 이름과 할인 금액 저장
- [x] 평일/주말 할인 적용된다면, 이벤트 이름과 할인 금액 저장
- [ ] 특별 할인 적용된다면, 이벤트 이름과 할인 금액 저장
- [x] 증정 혜택 적용된다면, 아밴투 아름과 증정 상품 금액 저장
#### 5. 사용자 입력 데이터에서 주문한 메뉴와 개수 추출
- 조건
- [x] `,`와 `-`를 구분자로 `.split()`해서 메뉴와 개수 추출
- [x] 추출된 결과에서 `Order`의 주문 목록에 메뉴와 개수 저장
- 예외
- [x] 음료만 주문한 경우, "[ERROR] 음료만 주문할 수 없습니다. 다시 입력해 주세요."
#### 6. 받을 수 있는 이벤트 혜택 출력
- 조건
- [x] `System.out.println()`으로 콘솔에 결과 출력
- [x] 제공된 `Output` 클래스 활용
- [x] 예약 날짜와 기본 문구 출력
- [x] 각 출력은 빈 문자열 개행을 기준으로 나뉘어짐
- [x] 금액은 1,000 단위로 `,`를 이용해 구분지어 표시할 것
- [x] <주문 메뉴> 아래, 메뉴와 개수 출력
- [x] <할인 전 총주문 금액> 아래, 금액 출력
- [x] <증정 메뉴> 아래, 증정 있으면 증정 메뉴와 개수, 없으면 "없음" 출력
- [ ] <혜택 내역> 아래, 적용된 이벤트 있으면 이벤트 이름과 확인된 금액 목록, 없으면 "없음" 출력
  - ex. `평일 할인: -4,046원`
- [ ] <총 혜택 금액> 적용된 금액 없으면 "0원" 출력
- [ ] <할인 후 예상 결제 금액> 출력
- [ ] <12월 이벤트 배지> 해당 사항 있으면 출력, 없으면 "없음"
